# CacheMux

**CacheMux** is a lightweight, privacy-first browser extension for inspecting and editing client-side storage (cookies, localStorage, sessionStorage) on the active tab.

Built for developers, cybersecurity professionals, and debugging workflows.

## Features

* View and edit **cookies** for the current domain
* Inspect and modify **localStorage** and **sessionStorage**
* 🔮 **Predict** encoding (JWT, Base64, Base32, Hex, URL-encoded, tokens)
* Quick actions: refresh, clear cookies/storage

---

## Privacy

* Works only on the **active tab**
* No network requests (no APIs, no tracking)
* No external storage or data collection
* Runs completely **locally**

## Installation

### Chrome / Brave / Edge

**Method 1 — Load Unpacked**

1. Open `chrome://extensions/` (or `edge://extensions/`)
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select the project folder

**Method 2 — ZIP**

1. Download the `.zip` from Releases
2. Extract it
3. Load unpacked using the steps above

---

### Firefox

**Method 1 — Temporary Load**

1. Open `about:debugging#/runtime/this-firefox`
2. Click **Load Temporary Add-on**
3. Select `manifest.json`

**Method 2 — XPI**

1. Download the `.xpi` file from Releases
2. Open Firefox → `about:addons`
3. Click ⚙ → **Install Add-on From File**
4. Select the `.xpi` file

1. Open any website
